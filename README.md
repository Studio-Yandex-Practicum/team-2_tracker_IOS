# Expense Tracker — трекер расходов, который всегда под рукой.

Это мощное и при этом простое в использовании приложение для учёта расходов и анализа личных финансов. 

## Возможности

- Полноценная система аутентификации: регистрация, авторизация и восстановление пароля.
![Авторизация — пусто](https://github.com/user-attachments/assets/9fd6f9f1-5d09-4ddf-abf6-66a6bebc9a42)
![Регистрация — заполнение](https://github.com/user-attachments/assets/463e129d-bf68-4b0d-a286-04adcbf398e4)
![Восстановить пароль — почта](https://github.com/user-attachments/assets/da52650d-d536-4592-b929-8027469b8a27)

- Поддержка смены темы (темная и светлая).
![Список расходов-1](https://github.com/user-attachments/assets/a80df186-a158-481a-84d3-19d7891a9332) ![Список расходов](https://github.com/user-attachments/assets/ca8132e2-41a6-4d71-bd17-6336eae2a49c)

- Удобный учёт расходов: добавлять, редактировать и удалять траты легко и быстро.
- Расходы можно группировать по категориям — можно выбрать из встроенных или создать собственные категории с уникальной иконкой.
- Сортировка и фильтрация расходов по дате, сумме и категориям.

**Глубокая и красивая аналитика**
Раздел Аналитики предоставляет цветную анимированная круговая диаграмму. Теперь можно наглядно увидеть, куда уходят деньги — по категориям и процентам.
Под диаграммой — список всех категорий с возможностью сортировки по суммам и временным отрезкам.

## Дополнительно
- Экспорт расходов в формате CSV — удобно для импорта в Excel, Google Sheets или отправки.
- Архитектура спроектирована с прицелом на масштабирование и читаемость кода.

## Технологии

- **UI Framework**: UIKit
- **Архитектура**: MVVM + Coordinators
- **Хранение данных**: Core Data
- **Авторизация**: Firebase Auth
- **Аналитика**: SwiftUI Charts (интеграция в UIKit)
- **Линтер**: SwiftLint
