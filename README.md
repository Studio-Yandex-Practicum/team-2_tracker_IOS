# Expense Tracker — трекер расходов, который всегда под рукой.

Это мощное и при этом простое в использовании приложение для учёта расходов и анализа личных финансов.

**Глубокая и красивая аналитика**
Раздел Аналитики предоставляет цветную анимированная круговая диаграмму. Теперь можно наглядно увидеть, куда уходят деньги — по категориям и процентам.
Под диаграммой — список всех категорий с возможностью сортировки по суммам и временным отрезкам.

## Дополнительно
- Экспорт расходов в формате CSV — удобно для импорта в Excel, Google Sheets или отправки.
- Архитектура спроектирована с прицелом на масштабирование и читаемость кода.

![Настройки](https://github.com/user-attachments/assets/c40b49b5-5a7c-4586-9ec9-0fa89fabdbc2)

## Технологии

- **UI Framework**: UIKit
- **Архитектура**: MVVM + Coordinators
- **Хранение данных**: Core Data
- **Авторизация**: Firebase Auth
- **Аналитика**: SwiftUI Charts (интеграция в UIKit)
- **Линтер**: SwiftLint
